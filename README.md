# 🎮 虚拟化弹窗解决工具

**适用场景：玩腾讯游戏《无畏契约》《三角洲行动》时，遇到虚拟化相关弹窗。**

这个工具通过关闭 Windows 的 Hyper-V 及相关功能，尝试处理虚拟化冲突。本仓库分享程序原文件和使用说明，方便有相同问题的玩家下载参考。

> 💡 请先核对弹窗内容：本工具执行的是“关闭 Windows 虚拟化相关功能”。如果报错要求开启某项安全或虚拟化功能，请按游戏官方指引处理。

## 🚀 怎么使用

1. **保存工作并退出游戏**，建议提前创建系统还原点。
2. 下载上方的 EXE 文件，右键选择 **以管理员身份运行**。
3. 等待程序处理完成，出现“操作完成！重启电脑后生效”提示。
4. **手动重启电脑**，再打开游戏检查弹窗是否消失。

效果取决于具体报错、系统配置和游戏版本；本仓库尚未进行游戏实测。如果重启后仍有弹窗，请保留完整报错信息，按游戏官方指引继续排查。

## ⚠️ 使用前了解这两点

- **虚拟化软件可能受影响**：Hyper-V、WSL 2、Windows 沙盒，以及依赖相关功能的 Docker Desktop 等软件可能无法正常使用。
- **部分系统安全保护会被尝试关闭**：包括 VBS、内存完整性、Credential Guard 等。需要这些功能的电脑，请先评估是否适合使用。

需要恢复时，应按原有配置重新启用相关组件、安全设置和启动选项，或使用事先创建的系统还原点；单独修改一条启动命令无法完整还原所有设置。

## 🔍 工具会修改什么

根据对当前 EXE 的静态分析，程序会尝试执行以下操作，具体结果取决于系统状态：

| 修改项 | 操作 |
| --- | --- |
| Windows 组件 | 禁用 Hyper-V、虚拟机监控程序平台、虚拟机平台、Windows 沙盒等 |
| 启动配置 | 执行 `bcdedit.exe /set hypervisorlaunchtype off` |
| 安全设置 | 修改 VBS、内存完整性、Credential Guard 等相关注册表设置 |
| 服务 | 检查 `HvHost`、`vmms`，在满足程序条件时将其启动方式改为手动 |
| 日志 | 包含日志路径 `log\hyperV_disable.log` |

上述信息来自静态分析，未运行程序验证。未发现直接修改 BIOS/UEFI 中 VT-x、AMD-V 或 SVM 开关的证据。
